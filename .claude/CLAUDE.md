# CLAUDE.md

# このプロジェクトについて

Next.js (App Router) 製の個人ポートフォリオサイト。パッケージマネージャーは **bun**。

不明点がある場合は推測で実装せず、確認事項として提示する。

---

# 優先順位

複数のルールが競合する場合は、以下の優先順位で判断する。

1. ユーザーからの指示
2. CLAUDE.md
3. rules/
4. README.md

---

# 基本ルール

- すべての回答・コメント・ドキュメントは日本語で記述する。
- TypeScriptでは `any` を使用しない。
- 不要なライブラリは追加しない。
- 不要なリファクタリングは行わない。
- 指示された範囲以外のコードは変更しない。
- 推測で仕様を決定しない。
- パッケージ操作は `bun` を使う（`yarn` / `npm` は使わない）。ロックファイルは `bun.lock`。

---

# Git運用

- 作業開始前に新しいブランチを作成する。
- mainブランチへ直接コミットしない。
- 実装完了後は Pull Request を作成する（説明は日本語）。
- コミット・pushはユーザーから依頼があった場合のみ行う。

詳細は `rules/git.md` を参照する。

---

# 実装ルール

`rules/` を各ドメインの正本とする。

- `rules/nextjs.md`
- `rules/react.md`
- `rules/security.md`
- `rules/git.md`
- `rules/documentation.md`
- `rules/testing.md`

---

# 完了前の確認

- `bun run build` が通る
- `bun run lint` が通る
- 変更が依頼範囲に収まっている

---

# 回答方針

- 根拠を示して回答する。
- 推測で断定しない。不明な場合は「確認できません」と回答する。
- 保守性・可読性・型安全性を優先する。
