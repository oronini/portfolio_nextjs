# Testing Rules

## 現状

テストフレームワークは未導入。導入する場合はユーザーに確認してから行う。

## 検証手順（現状の最低ライン）

実装後は以下を実施する。

1. `bun run lint`
2. `bun run build`（型チェック・静的生成を含む）
3. `bun run dev` で該当ページが表示できることを確認する
4. 問い合わせフォームを変更した場合は、正常系・入力エラー・送信失敗の挙動を確認する
   （実際のメール送信を伴う確認はユーザーの了承を得てから行う）

## 報告

- 実行したコマンドと結果を正直に報告する。
- 実行していない確認は「未確認」と明記する。
